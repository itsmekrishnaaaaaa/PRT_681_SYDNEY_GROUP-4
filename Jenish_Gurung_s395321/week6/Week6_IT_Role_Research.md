# Week 6 – Individual Task: IT Role Research
**Jenish Gurung**

## 1. Business Analyst

### Overview
A Business Analyst bridges the gap between business stakeholders and technical teams, translating business needs into clear requirements that guide software development.

### Skills Required
- Requirements gathering and elicitation (interviews, workshops, surveys)
- Stakeholder communication and management
- Process modelling and mapping (BPMN)
- Documentation writing (BRD, SRS, use cases)
- Basic SQL for data querying
- Problem-solving and critical thinking

### Tools
- **Documentation/Collaboration:** Microsoft Office (Word, Excel, Visio), Confluence
- **Project Management:** Jira
- **Diagramming:** Lucidchart, Draw.io
- **Data:** SQL, Excel (pivot tables, basic analysis)

### Learning Path (1 Month)
| Week | Focus | Milestone |
|------|-------|-----------|
| 1 | BA fundamentals – requirements gathering, BRD/SRS basics | Complete an intro BA course (e.g. LinkedIn Learning) |
| 2 | Process modelling – BPMN, use case diagrams | Create a BPMN diagram for a sample process |
| 3 | Tools practice – Jira, Confluence, Visio | Set up a mock project board with backlog items |
| 4 | Applied practice – write a sample BRD/SRS | Produce a small BRD/SRS document for a mock project |

## 2. Report Writer

### Overview
A Report Writer/Technical Writer turns project activity, data, and findings into clear, structured documentation — progress reports, project reports, and technical write-ups that stakeholders and teams rely on to track and understand a project.

### Skills Required
- Clear, structured technical writing
- Summarising complex information for different audiences
- Data interpretation (turning raw data/backlog activity into a narrative)
- Attention to detail and consistency in formatting/style
- Time management for recurring reporting deadlines
- Basic familiarity with data visualisation for reports

### Tools
- **Writing/Documentation:** Microsoft Word, Confluence, OneNote
- **Reporting/Visualisation:** Power BI, Tableau (for report dashboards)
- **Version Control (for markdown reports):** GitHub
- **Collaboration:** Jira (for pulling status/progress into reports)

### Learning Path (1 Month)
| Week | Focus | Milestone |
|------|-------|-----------|
| 1 | Technical writing fundamentals – structure, tone, clarity | Complete a short technical writing course |
| 2 | Reporting tools – Power BI/Tableau basics | Build a first simple report dashboard |
| 3 | Practice writing project status reports | Write a sample weekly project status report |
| 4 | Applied project | Produce an end-to-end project report section combining data + narrative |

---

## Summary
Both roles complement each other directly on OraEarn — the Business Analyst role drives requirements and backlog definition, while the Report Writer role documents and communicates that progress in the ongoing project report.
